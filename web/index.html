Policy Explainability & Drift Dynamics

Physical reasoning behind optimal syndrome-to-correction mappings.

Syndrome [0, 0] ➔ Action: No correction (000)
All parity checks match. Zero physical errors is the maximum likelihood state.
Syndrome [0, 1] ➔ Action: Flip Q₂ (001)
Parity check (q₁, q₂) fired while (q₀, q₁) passed. Qubit 2 is the odd qubit out.
Syndrome [1, 0] ➔ Action: Flip Q₀ (100)
Parity check (q₀, q₁) fired while (q₁, q₂) passed. Qubit 0 is the odd qubit out.
Syndrome [1, 1] ➔ Action: Flip Q₁ (010)
Both checks fired. Qubit 1 is entangled in both checks, resolving both simultaneously.

Why Adaptive RL Beats Fixed MWPM Under Asymmetric Drift:

When hardware noise degrades $q_2$ severely ($p_{q2} \gg p_{q0}$), weight-2 errors involving $q_2$ become more probable than single errors on $q_0$. Fixed MWPM continues to assume uniform noise weights and guesses incorrectly, while Adaptive RL adjusts the action for state [1,0] from flip $q_0$ to flip $q_2$, dropping the logical error rate by over 7×.

B.Tech Major Project Research Synthesis

Academic conclusions, verified empirical benchmarks, and examiner viva cheat sheet.

01

The Core Research Problem

Can model-free reinforcement learning decode quantum error codes, and how does performance degrade when real hardware noise drifts away from training calibration?

02

Uniform Noise Drift Null Result

Under uniform noise scaling, relative error likelihood order remains invariant, meaning static matching graphs remain mathematically optimal.

03

Asymmetric Drift: The 7.2× Leap

When physical qubits drift unevenly ($\alpha = 1.0$), Fixed MWPM fails at LER = 0.00210, while Adaptive RL recovers LER = 0.00029 (a 7.2× improvement).

04

Selective Adaptation Efficiency

Online updates trigger only when empirical drift exceeds threshold, capturing 95% of oracle recovery while reducing compute overhead by >90%.
